# 🎬 CultureAdapt AI

## Cultural Screenplay & Visual Adaptation Studio

CultureAdapt AI is an **Agentic AI-powered application** that transforms a generic screenplay into a culturally specific screenplay and visual production pack using **Google Gemini**.

The application extracts scenes, characters, costumes, props, locations, and continuity information, creates canonical entities, prepares a cultural adaptation plan, allows human approval, and generates an adapted screenplay and visual assets.

---

## 🚀 Key Features

- 📄 Upload PDF, DOCX, or TXT screenplay
- 🌍 Select culture, dialect, region, and setting
- 🤖 AI-based screenplay extraction using Gemini
- 👤 Canonical character identification
- 👕 Costume and prop tracking
- 🔄 Scene and continuity validation
- 🧠 Cultural adaptation planning
- 👨‍💻 Human approval before generation
- 📝 Adapted screenplay generation
- 🎨 Character, costume, and scene visual pack
- 🧪 Automated continuity tests
